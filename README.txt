Greek NT Reader — Galatians 2–6 Update

2. index.html과 갈라디아서 HTML 6개를 기존 Greek NT Reader의 index.html과 같은 폴더에 올립니다.
3. 기존 요한복음 1–21장 HTML은 그대로 둡니다. 이 ZIP에는 요한복음 파일을 넣지 않았습니다.
